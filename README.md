1. Sistema de Biblioteca
Objetivo: criar um sistema para gerenciar livros e empréstimos.

Conceitos: classes, objetos, atributos e métodos.


Crie as classes:
- Livro
- Usuario
- Biblioteca
Requisitos:
1. Cada livro deve possuir título, autor, ISBN e disponibilidade.
2. Cada usuário deve possuir nome e ID.
3. A biblioteca deve armazenar vários livros.
4. Criar método para cadastrar livros.
5. Criar método para listar todos os livros.
6. Criar método para buscar um livro pelo título.
7. Criar método para emprestar um livro.
8. Criar método para devolver um livro.
9. Impedir empréstimo de livros indisponíveis.
10. Exibir mensagens informando o sucesso ou falha das operações.
  
3. Método para sacar.
4. Método para consultar saldo.
5. Não permitir depósitos negativos.
6. Não permitir saques maiores que o saldo.
7. Criar método para transferir dinheiro entre duas contas.
